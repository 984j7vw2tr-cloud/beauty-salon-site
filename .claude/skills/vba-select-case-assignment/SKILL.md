# プログラミング課題1-2 のスプレッドシート作成

成果物はスプレッドシート1つ。ファイル名は「プログラミング2」。

## 作り方
1. `python3 make_workbook.py プログラミング2.xlsx` を実行する(openpyxl が必要。このフォルダで実行)。
2. 2シートのブックができる。
   - 「Select～Case」: 4つの実習(部署名 C10 / プレゼント C19 / 自動車区分 C27 / 色 C34)と各対応表
   - 「血圧判定」: 性別 C3・年齢 C4・血圧 C5・判定 C6 と年齢別の目安表
3. ユーザーにはそのファイルだけを渡す。保存先はユーザーが指定した場所。

## 注意
- ボタンとマクロは openpyxl では作れない。ブックにはボタン位置のメモ(「→ マクロ: ○○」)を入れてある。
- マクロ入りの `.xlsm` が必要なときは、同フォルダの `Module1.bas`(Shift-JIS)を Excel の VBE でインポートし、ボタンに割り当ててから .xlsm で保存してもらう。
- 元の課題ファイルがユーザーから渡された場合は、それを開いて同じシート構成で上書きする。
